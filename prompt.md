Build a native Android movie streaming application called RMovie using Kotlin and Jetpack Compose.

1. Research First

- Locate and inspect "lk21.apk" using JADX or APKTool.
- Analyze its UI, application structure, libraries, and networking implementation.
- Fetch and investigate the publicly accessible LK21 website.
- Identify and document available APIs, endpoints, and response structures.
- Only use legally accessible endpoints and authorized streaming sources.

2. Build the Application

Use:

- Kotlin
- Jetpack Compose
- Material 3
- MVVM architecture
- Retrofit or Ktor
- Room Database
- DataStore
- Navigation Compose
- Android Media3 ExoPlayer

Create a modern dark-themed movie streaming application.

3. Main Features

Home

- Featured movies.
- Trending and popular movies.
- Latest releases.
- Recommended movies.
- Genre categories.

Search

- Search movies by title.
- Search suggestions.
- Search history.
- Genre filtering.

Movie Details

- Poster and backdrop.
- Title, synopsis, rating, and release date.
- Genres and other information.
- Similar movies.
- Watch button.
- Favorite button.

Video Player

Implement a fully functional Media3 ExoPlayer with:

- HLS, DASH, and MP4 support.
- Automatic and manual quality selection.
- Multiple authorized streaming sources.
- Playback speed control.
- Subtitle and audio track selection.
- Fullscreen mode.
- Seek controls.
- Resume playback.
- Buffering indicators.
- Picture-in-Picture.

Ensure proper stream parsing, track selection, and playback configuration for smooth playback.

Other Features

- Favorites.
- Watch history.
- Continue Watching.
- Download manager for authorized offline content.
- Settings and playback preferences.

4. UI/UX

- Modern dark interface.
- Clean movie cards.
- Smooth animations.
- Responsive layouts.
- Professional streaming-platform design.

5. Development Instructions

Work incrementally:

1. Inspect existing files and analyze LK21.
2. Research available APIs and data sources.
3. Set up the Android project.
4. Implement the main UI and navigation.
5. Connect real movie data.
6. Implement the video player.
7. Add favorites, history, and downloads.
8. Build and fix errors.

Important

- Do not build everything in one step.
- Do not use fake APIs or placeholder functionality.
- Keep the code modular and maintainable.
- Do not modify unrelated files.
- Verify endpoints before integrating them.
- Do not bypass DRM or access restrictions.
- Test each feature before moving to the next phase.

Start by inspecting the workspace and locating "lk21.apk". Then proceed with implementation step by step.

The final result must be a working Android application, not just a UI prototype.
